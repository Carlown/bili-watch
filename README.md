# 投稿观察 Bili Watch

双击 `BiliWatch.exe` 启动。源码目录可双击 `start.cmd`。

默认监控 UID `1263732318`，可在面板“监控 UID”一栏改成其他 B 站数字 ID，更改后会为该账号重新建立基线，原账号的记录仍保留、可随时切回。第一次读取只保存最新可见投稿作为基线；之后检查新增，按 BV 号去重。默认每 10 分钟检查，界面可调整、暂停或立即检查。无需安装 Python；独立登录窗口优先使用本机 Edge，未安装时尝试 Chrome，并以 `--new-window` 启动为单独窗口。

程序打开本地面板。点“启用桌面提醒”，允许浏览器通知，并保持面板打开（可最小化）。处理模式有两种：默认“人工审核”会保存证据、时间点和处理状态，由你在 B 站手动提交；切换到“机器自动举报”后，必须先在独立登录窗口完成登录并点击确认，之后仅对非基线、投稿简介中带明确原片链接的新投稿，通过同一已登录监控浏览器选择“侵权”并提交一次，结果会写回记录。标题末尾推测出的链接不会进入自动举报队列。

面板会读取每条投稿在 B 站的“自制 / 转载”标记，并据此推断可投币上限：标注转载的稿件只能投 1 个币，标注自制的可以投 2 个币。因此“仅可投 1 币”说明作者承认这是搬运，“可投 2 币”则说明这条翻译搬运被标成了自制，面板会标出“疑似转载投自制”并计入统计。默认对基线之后的新投稿自动检测（可在面板关闭），也可以点“检测投币上限”重新核查已存档记录，或对单条点“重测投币”。数据取自 B 站公开的视频详情接口，不需要登录，也不读取账号信息；接口不可用时该条会显示“检测失败”，可随时手动重测。

B 站当前把“侵犯个人知识产权”等版权原因分流到独立的版权投诉页。工具会点击举报弹窗中的“下一步”，捕获新打开的投诉窗口，选择“路人”，自动填写原片出处，并按内置举报词生成说明（“举报词设置”里可改，支持 {title}、{bvid}、{url}、{source}、{coin} 占位符，提交时替换为当前记录内容，超过版权投诉页上限的 400 字会被截断），再点击“提交举报”。流程继续使用独立登录窗口中的会话，不读取或要求提供账号、密码或 Cookie。若页面要求实名认证、验证码、附件，或网站改动导致字段/按钮无法定位，工具会保留页面和诊断文件并将记录标记为“提交失败”，不会伪造成功状态。普通社区原因会在举报 iframe 内自动填写描述并定位“提交举报”按钮。

如果自动举报失败，记录的“举报状态”会显示“提交失败”，操作列会出现“重试举报”。点击后会清除旧错误、重新加入自动举报队列，并唤醒下一轮处理；只有失败记录可以重试，已经提交的记录不会重复提交。重试仍使用独立登录窗口中的会话，人工审核模式下重新入队的记录会在切换到机器自动举报后处理。

遇到网站登录或验证提示，点“打开独立登录窗口”。程序会启动一个单独的可见浏览器窗口，并使用独立的 `EdgeProfile`，不会读取日常浏览器的登录资料。请只在这个窗口内登录 B 站；登录完成后回到工具点“我已登录，开始举报”，程序检测到该窗口的登录 Cookie 后才会放行自动举报。不需要把账号、密码或 Cookie 提供给程序或 AI。网页结构或网站访问策略变化可能影响读取，失败会显示原因并延长重试间隔。

长期离线后的积压会分批补查；有未完成分页时面板会显示提示。动态流仅涵盖网站当前可见记录，无法保证恢复离线期间已删除、隐藏或未出现在动态流中的投稿。首次基线不会遍历账号全部历史。

数据默认保存在 `%LOCALAPPDATA%\BiliWatch`：

- `records.sqlite3`：投稿、核实笔记、版权标注与投币上限、举报词设置、分页进度和当前监控的 UID；每条记录都带有账号 UID，面板只显示当前账号。
- `EdgeProfile`：工具独立的浏览器资料。
- `monitor.log`：运行错误与检查日志。

关闭面板不会停止程序；使用面板右上角“关闭工具”。再次双击程序会打开已有面板，不会重复启动监控。点“导出证据 CSV”可保存全部记录，以 UTF-8 BOM 编码兼容中文 Excel。

源码运行和定向验证：

```powershell
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest tests -v
```

打包（`BiliWatch.spec` 已包含 `web/` 资源和程序图标，产物为 `dist\BiliWatch.exe`）：

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --distpath dist BiliWatch.spec
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

重新创建构建环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller==6.22.1
```
